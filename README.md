## About

**Ariya** is a modern Android music player built with a focus on elegance, performance, and user experience. It provides a seamless music listening experience with features like synced lyrics, lossless audio support, multiple audio sources, and Discord integration.

## Features

| Feature | Description |
|---------|-------------|
| Music Playback | Smooth, high-quality audio playback with gapless and crossfade support |
| Music Discovery | Discover new music through multiple audio sources |
| Lyrics | Follow along with synced lyrics while you listen |
| Playlists | Create and manage your own playlists |
| FLAC Support | Enjoy lossless audio with FLAC and hi-res support |
| Audio Quality | Choose from multiple quality options from low to ultra-high |
| Queue & Controls | Full queue management with drag-to-reorder, play next, shuffle, repeat |
| Multiple Sources | Access music from multiple audio sources |
| Discord Integration | Share what you're listening to with your Discord community |

## System Requirements

| Requirement | Details |
|-------------|---------|
| OS | Android 8.0 (Oreo) or later |
| Storage | ~30 MB free space |
| Architecture | arm64, armv7, x86, x86_64 |
| Network | Internet for streaming and discovery |

## Download

Download the latest release from the [Releases](https://github.com/vickyhubhai/Ariya/releases) page.

> **Note:** Ariya is currently available for Android only. iOS support is not available at this time.

## Installation

1. Download the latest `Ariya.apk` from [Releases](https://github.com/vickyhubhai/Ariya/releases)
2. Enable "Install from unknown sources" on your Android device if prompted
3. Open the downloaded APK file
4. Follow the on-screen instructions to install

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design:** Glassmorphism, 3D animations, responsive design
- **API:** GitHub Releases API for auto-updates
- **PWA:** Service Worker + Manifest for installability
